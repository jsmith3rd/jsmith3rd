# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Repository Purpose

This is a GitHub profile repository (`jsmith3rd/jsmith3rd`). Its sole content is `README.md`, which GitHub automatically renders as the profile page at `github.com/jsmith3rd`. There is no build system, no tests, and no application code.

## Structure

- `README.md` — the profile page displayed on GitHub, written in GitHub Flavored Markdown with badge links using `shields.io` and `custom-icon-badges.demolab.com`

## Conventions

- Badges use `style=flat-square` consistently
- Badge image URLs follow the pattern: `https://img.shields.io/badge/<label>-<message>-<color>?style=flat-square&logo=<logo>&logoColor=<color>`
- Contact and social badges at the top use `custom-icon-badges.demolab.com` for custom icons (globe, email)
- The profile links to `jsmith3rd.dev`, LinkedIn at `linkedin.com/in/jsmith3rd`, and email `hello@jsmith3rd.dev`

## Making Changes

All changes are edits to `README.md`. After editing, commit directly and push to `main`.
